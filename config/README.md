# Configuration

This folder will hold configuration files for the Sentinel project.

## Ideas for later
- `config/env/` – environment settings (dev vs. production).
- `config/hardware/` – notes/configs for devices, wiring, and access control gear.
- `config/app/` – app‑level settings (feature flags, integration endpoints, etc.).

For now this is just a parking spot so we don’t dump config into `src/` by accident.
