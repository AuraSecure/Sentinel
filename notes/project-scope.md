# Project Scope

This file is where Sentinel stops being a cool name with folders and starts becoming an actual project.

## Working idea
Sentinel is a project that may combine hardware, software, and practical field logic into something useful and organized.

## What this project might include
- Hardware-related ideas
- Software tools or dashboards
- Access control or low-voltage related workflows
- Automation that saves time or reduces repetitive work

## What still needs to be decided
- What the first real version should do
- Who it is for
- What problem it solves first
- What part gets built first

## Rule
If we are arguing with ourselves about what Sentinel is, this is the file we come back to.
