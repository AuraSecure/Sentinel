# First Version

This file defines the first version of Sentinel so we build something real instead of lovingly organizing an empty garage.

## Goal
The first version of Sentinel should be small, useful, and realistic enough that it can actually get finished.

## Rules for version one
- Keep it simple
- Solve one real problem first
- Avoid building five side quests by accident
- Prefer something testable over something impressive sounding

## Questions to answer
- What is the first job Sentinel should do?
- Is the first version mostly hardware, software, or both?
- Who is it for first: me, a technician, a customer, or a team?
- What would make version one feel genuinely useful?

## Working standard
If a feature does not help version one become real, it can wait.
