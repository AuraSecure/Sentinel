# Source Code

This folder will hold the actual code for the Sentinel project.

## Ideas for structure
- `src/api/` – any HTTP or device APIs we talk about.
- `src/client/` – front‑end pieces (React, etc.).
- `src/server/` – backend / scripts (Python, Django, tooling).
- `src/tools/` – little utilities or test scripts.

Right now this is just a parking lot for code as the project grows.
